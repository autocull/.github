# AutoCull Brand Assets

| File | Intended use |
| --- | --- |
| `autocull-avatar.jpg` | Primary organization avatar and compact brand mark; tightly cropped for small UI sizes |
| `autocull-mark-square.jpg` | Original icon-only square with wider padding |
| `autocull-wordmark-square.jpg` | Square promotional image where the AutoCull name must appear inside the artwork |
| `autocull-banner.jpg` | Primary public README banner with product promise and core principles |

## Usage guidance

Use the icon-only mark for GitHub, social avatars, favicons, and other small or
circular placements. Text embedded in an avatar becomes unreadable at normal UI
sizes, while the stacked-photo silhouette remains identifiable.

Use the wordmark variant for larger square placements such as announcement
cards. In documents and web pages, prefer the icon-only mark beside real text
so the product name remains searchable, selectable, accessible, and sharp at
every display size.

The banner is designed for wide README and organization-profile placement. Its
meaningful text is repeated in the surrounding document or image alt text so
the public message remains accessible when the artwork is scaled down.
